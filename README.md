# GREEN-API Test Task

Тестовое задание с использованием GREEN-API.

## Реализованные методы

- getSettings
- getStateInstance
- sendMessage
- sendFileByUrl

## Возможности

Приложение позволяет:

- получить настройки инстанса;
- получить состояние инстанса;
- отправить текстовое сообщение в WhatsApp;
- отправить файл по URL;
- просматривать ответы GREEN-API в отдельном поле;
- отображать сообщения об ошибках и проверять обязательные поля.

## Использованные технологии

- HTML
- CSS
- JavaScript
- GREEN-API

## Запуск

Откройте `index.html` в браузере и введите:

1. `idInstance`
2. `ApiTokenInstance`

Для отправки сообщений укажите `chatId` в формате:

`77771234567@c.us`

Для отправки файла также укажите публичный URL файла и имя файла с расширением.

## Безопасность

`idInstance` и `ApiTokenInstance` не хранятся в исходном коде приложения. Пользователь вводит их непосредственно в интерфейсе.
